# MultiNodeDAQ Desktop

Implemented Windows WPF operator interface. See [operator guide](../../docs/stage4-operation.md), [plotting decision](../../docs/stage4-plotting.md) and [test report](../../docs/stage4-test-report.md).

Start the independent host before connecting, or use **Start local service** for a loopback-only local receiver. Run the demo launcher for synthetic units. The GUI never owns recorder lifetime.
